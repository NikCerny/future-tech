# Future Tech

A responsive frontend project built with HTML, SCSS, and Vanilla JavaScript.

## About

Future Tech is a practice frontend project based on a [Figma design](https://www.figma.com/design/YzTDRV7OaSoeCUBNYaoCZV).

The project focuses on clean layout structure, reusable SCSS architecture, and responsive typography.

## Tech Stack

- HTML5
- SCSS (Sass)
- CSS3
- Vanilla JavaScript
- npm

## Project Structure

- `index.html` - main page
- `styles/` - SCSS source files
- `styles/helpers/` - functions, mixins, and media helpers
- `images/` - images
- `icons/` - icons
- `fonts/` - fonts
- `scripts/` - JavaScript files

## Getting Started

Install dependencies:

```bash
npm install
```

Run Sass watcher:

```bash
npm run sass-watch
```

## Available Script

```bash
npm run sass-watch
```

Watches SCSS files and compiles styles automatically.
